# Security+ SY0-701 Study Command Center

A local HTML/CSS/JavaScript study tracker for a 2-month CompTIA Security+ SY0-701 course.

## How to run on Windows

1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html`.
4. Use Chrome or Microsoft Edge.

Do not open `index.html` from inside the ZIP file. Extract first.

## What changed in v2

- Cleaner homepage with sidebar navigation
- Continue Learning card for the next incomplete day
- Quick actions section
- Weekly roadmap cards
- Domain-based navigation for weak-area repair
- Filterable resource library by type
- Same progress tracking, weakness tracking, score tracking, memory system, and final checklist

## Data storage

Progress is saved in browser localStorage. Use the same browser every time. Export JSON regularly if you do not want to lose progress.
